# Expected Experimental Outputs

This directory describes the format and structure of the data generated by the `campaign_runner.sh` script. Upon successful execution of an experimental run, a new directory is created under `results-campaign/` containing the following assets.

## 1. Latency & Performance Metrics (`scientific_latency_*.csv`)

This file captures the per-stage timing information for each data record.

| Column | Description |
| :--- | :--- |
| `run_id` | Unique identifier for the experimental run. |
| `producer_id` | The edge node or simulated source that generated the record. |
| `edge_to_fog_ms` | Network transit time from the Edge ingestion point to the Fog tier. |
| `eprem_processing_ms` | Processing time spent within the Fog mediation layer. |
| `forecast_ts` | Logical timestamp associated with the decision or estimation. |
| `source_log` | Reference to the log file where the event was captured. |

## 2. Resource Utilization (`resource_utilization_*.csv`)

Samples collected at 5-second intervals from the compute nodes.

| Column | Description |
| :--- | :--- |
| `timestamp` | Unix epoch time of the sample. |
| `cpu_percent` | CPU load percentage. |
| `ram_used_mb` | Memory usage in MB. |
| `net_bytes_recv/sent` | Cumulative network throughput. |
| `cpu_temp_c` | Thermal metrics (available for physical Edge configurations). |

## 3. Logs (`logs/` directory)

A collection of standard output/error logs from the distributed microservices:
- `edge_*.log`: Ingestion daemon logs.
- `fog_*.log`: Mediation and normalization logs.
- `cloud_*.log`: Analytics engine and Digital Twin decision logs.

## 4. Metadata (`experiment_metadata.json`)

A JSON descriptor recording the environment parameters:
- Active ingestion mode (streaming vs polling).
- Infrastructure topology.
- Software versions and environment variables.
